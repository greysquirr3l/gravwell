## 📖 Name Origin

**Gravwell** = **Grav**ity + **Well**

A **gravity well** is the fundamental concept in physics describing how mass curves spacetime, creating the "well" that objects fall into. It's a perfect metaphor for:

- The physics we're simulating
- The depth and accuracy of the simulation
- The pulling together of game dev and scientific communities

## 🎭 Personality & Voice

**Gravwell's voice is:**

- **Technical but accessible** - We explain complex physics clearly
- **Precise but friendly** - Accurate without being pedantic
- **Confident but humble** - We know our strengths, acknowledge tradeoffs
- **Inclusive** - Welcoming to game devs AND scientists

**We DON'T:**

- Use excessive jargon without explanation
- Make unrealistic claims (we're realistic about performance)
- Dismiss either game dev or scientific use cases
- Assume prior physics knowledge

**We DO:**

- Provide working examples for everything
- Explain the "why" behind design decisions
- Compare honestly with alternatives (REBOUND, Rapier)
- Celebrate both fun projects and serious research

## 📊 Competitive Positioning

**vs. Game Physics Engines (Rapier, PhysX)**

- ✅ More accurate gravity (theirs is often simplified)
- ✅ Better for space/orbital games
- ✅ Scientific validation
- ⚠️ Less feature-complete for general rigid body physics

**vs. Scientific N-body Codes (REBOUND, NBODY6)**

- ✅ Real-time performance mode
- ✅ Better integration with Rust game engines
- ✅ Modern, safe Rust (not C/Fortran)
- ⚠️ Less mature, smaller user base (for now)

**Our Niche:**
The **only** library that genuinely serves both audiences without compromise.

## 📝 Documentation Tone Examples

**Bad (Too Technical):**
> "Gravwell implements O(N log N) gravitational force computation via hierarchical
> octree spatial decomposition utilizing the Barnes-Hut multipole acceptance criterion."

**Good (Accessible):**
> "For large particle counts, Gravwell uses the Barnes-Hut tree algorithm to calculate
> forces efficiently (O(N log N) instead of O(N²)). This speeds up simulations by 10-100×
> for systems with 1,000+ bodies."

**Bad (Too Casual):**
> "Yo, wanna make stuff orbit? We got you fam 🚀"

**Good (Friendly but Professional):**
> "Let's create a simple orbital system! This example shows how to set up Earth orbiting
> the Sun with realistic physics."
